# BookStore - Книжный магазин

Полнофункциональное веб-приложение книжного магазина с красивым интерфейсом и удобной навигацией.

## Структура проекта

```
сайтн/
├── index.html           # Главная страница
├── css/
│   └── style.css        # Стили оформления
├── js/
│   ├── main.js          # Основной скрипт
│   └── bookstore.js     # Логика приложения
├── images/              # Изображения
└── README.md            # Документация
```

## Возможности

- 📚 Каталог книг с фильтрацией и сортировкой
- 🔍 Поиск по названию и автору
- 🛒 Корзина покупок (localStorage)
- 📖 Раздел с категориями книг
- ⭐ Отзывы читателей
- ℹ️ Информация о магазине
- 💳 Оформление заказов
- 📱 Адаптивный дизайн

## Категории книг

- Художественная литература
- Нехудожественная литература
- Детские книги
- Образование
- Бизнес

## Установка и запуск

Просто откройте `index.html` в браузере или используйте локальный сервер:

```bash
# Python 3:
python -m http.server 8000

# Node.js:
npx http-server
```

Затем откройте: `http://localhost:8000`

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome Icons
- LocalStorage для корзины

## Функционал

### Поиск и Фильтрация
- Поиск по названию и автору книги
- Фильтрация по категориям
- Сортировка по популярности, цене, новизне

### Корзина
- Добавление/удаление книг
- Сохранение состояния (LocalStorage)
- Подсчет итоговой стоимости
- Оформление заказа

### Навигация
- Плавная прокрутка по секциям
- Выпадающее меню категорий
- Поиск в реальном времени
- Быстрые ссылки на разделы
